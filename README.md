[ Riyadh Metro Management System ]

An object oriented Java application simulating the Riyadh Metro ticketing system, user management, and train schedule handling using custom data structures without external databases.

-- Project Overview
- Core Functionality: Ticket booking, fare calculation, passenger profile management, and route planning.
- Architecture: Built using Object-Oriented Programming (OOP) principles across structured Java classes including custom data structures.
- Data Storage: In-memory data structures for managing system entities efficiently.

-- Technical Details
- Programming Language: Java
- Concepts Applied: Encapsulation, Inheritance, Polymorphism, Abstraction, Data Structures, and Algorithms.

-- Key Data Structures Implemented
- Priority Queue / Binary Heap (AHeap, AHNode)
- Queue (ArrayQueue)
- Binary Search Tree (BSTree, BSTNode)
- Circular Doubly Linked List (CircularDoublyList)
